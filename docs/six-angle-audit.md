## 特別重要的未完成事項

1. **真實底圖及整幅離線**：地政總署 API、Esri 等高線、BRouter 及 OpenTopoMap 的實際可用性、跨域和離線授權未由合成測試保證；實際政府 TIFF 未完成導入／解碼與紙圖對照。五張郊遊圖的合法整幅離線來源未確認。此版本只支援預載目前畫面及實驗性 iB20000 試用，**不等同已完成 16 張紙圖與 5 張郊遊紙圖整幅離線**。
2. **資料庫及帳戶**：模擬活動通過不代表正式 Redis 已連接。領袖密碼、Redis 與可選 `LEADER_SESSION_SECRET` 要由有權限的人在 Vercel 設定並重新部署，不要把秘密貼進 Git 或聊天。活動管理鑰匙在手機及私人備份明文存在，與 A1 有已知差距。
3. **版本與大小**：版本化 HTML 源與固定 Vite 入口由腳本同步，bundle 使用內容 hash；S7 `dist < 5 MiB` 是本專案的 CI 硬門檻，尚未達 G11 文檔列出的整站 `≤ 1 MB` 理想目標。生成 QR PNG 未嵌 W2/W3 隱形水印，也未建立圖片追溯紀錄。
4. **人工核實**：地名／圖例須領袖對照紙圖填寫；三個地標不能代替三角網測觀測；八位格是約 10 米方格中心，不是 GPS；紙圖角度、磁差和路網皆須實地核對。帶紙圖及指南針，不能單靠手機導航。

## 實機驗收建議

1. 在穩定 HTTPS 正式網址更新並加入主畫面，確認舊圖標快取是否影響顯示；以兩部不同裝置登入領袖／成員。
2. 領袖設三類題目，邊選點邊核對八位及方格北答案，展開整組答案總覽，再存私人備份；成員先掃問題，核對未公布的答案不可見。
3. 在全新成員裝置先掃答案 QR（不先掃題目），核對題目及所選答案；再測 JSON、不同版本、超長題組的錯誤提示及 JSON 後備。實際掃鏡頭與螢幕／紙上 QR 均要測。
4. 正式 Redis 配好後再測活動 QR、逐題公布、改題版本衝突、離線後重連、活動到期和不同領袖手機以私人備份還原管理權。備份需妥善保管及安全刪除。
5. 在可合法預載及可確認範圍的地圖上下載，切飛航、關閉重開，逐段核對兩底圖、地名、等高線、旋轉、比例、路線、GPX、方位與三角；任何缺圖、位置或授權疑點都不可用作導航。
