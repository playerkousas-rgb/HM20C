# 山野地圖 · Scout Trail Map

以手機操作為先的童軍遠足地圖及 GPX 路線工具。結合 [HKMAP](https://github.com/playerkousas-rgb/HKMAP) 的地政總署地形底圖及 iB20000 等高線，與 Draw the Route 的路線規劃概念；兩種底圖互相獨立，切換時不會混合地名、等高線或底圖。

## 功能

- **地形圖（HM20C 參考）**：預設使用地政總署 Topographic Map API 加中文地名，並顯示 HKMAP 使用的 iB20000 ELEVLINE 等高線（20 米高距、100 米計曲線），沒有關閉等高線的按鈕。載入失敗會警告，可重試。切換至本機 iB20000 TIFF 試用圖幅時不疊加這些圖層；TIFF 內的等高線及地名須另外核對。
- **郊遊圖參考**：獨立的 OpenTopoMap 地圖及其自帶的地形、路徑和地名；不疊加地政總署地名或 iB20000 等高線。
- **比例鎖定**：兩種模式分別按 1:20,000 及 1:25,000 的畫面比例顯示，禁止地圖滾輪、雙擊和觸控縮放；平移和置中路線不會解除鎖定。預設按 96 dpi **估算**，可用尺量度 200 CSS px 線段校準個別螢幕。比例是畫面中央的近似比例，改變瀏覽器縮放或屏幕方向後需重新校準；實地距離請以動態比例尺為準。
- **方向選擇**：地形圖預設按畫面中心所在的近似數碼圖幅，自動套用使用者提供的 2–16 號圖幅角度；亦可選「真北向上」或手動固定其中一個圖幅。正數表示圖像順時針、負數表示逆時針旋轉；圖幅外自動回到真北。地圖中的 `N` 是**真北**，不是磁北或手機指南針。郊遊圖保持獨立的真北向上，不套用地形圖角度。
- **繪製路線**：點選地圖加點、拖動路點、撤回、清除；計算每段的水平直線距離，不會自動貼合山徑或計算爬升。超過 150 個路線點時，仍可加點但不提供每點拖動。
- **GPX**：匯入航跡、路線和獨立航點；保留分段，不跨分段計算距離或連線。匯出已有的高度、時間和航點名稱；手繪點不會虛構高度或時間。GPX 的擴充資料等其他欄位目前不會保留。限制 5 MB / 30,000 點。
- **人手讀圖與保存**：不要求 GPS 定位或自動跟隨；使用者須自行以地形、地名、等高線、方向、紙圖和指南針判斷位置。畫面中央十字及「圖心」坐標只是目前視窗中央的坐標，不代表使用者位置。手機可按「收起路線」或底部「地圖」顯示更多地圖；開始繪路時可重新展開，比例、底圖及路線不受影響。路線及設定只保存在瀏覽器本機，GPX 在本機處理。可加入手機主畫面（視乎瀏覽器支援）。
- **手選地點書籤**：把地圖移到所需位置，按右側圖釘「選擇地區與書籤」，可為目前圖心命名、儲存、返回或刪除（最多 50 個）。書籤只儲存在這個瀏覽器／主畫面 App，不會上傳，也不會取得裝置位置或下載地圖；更換裝置、清除瀏覽器資料或使用另一瀏覽器可能失去書籤。返回書籤時維持當前底圖和比例，地形圖的自動方向可能隨圖心改變。離線前仍須另行預載並實際檢查該處畫面。
- **整幅地形圖（試用）**：可嘗試從地政總署直接下載指定 iB20000 數碼 TIFF，或在手機自行下載後選取 TIFF／ZIP 本機匯入，儲存在裝置 IndexedDB；檔案不經 Arena／Vercel。程式依地理參考分塊解碼並投影，不讀 GPS、不混入即時底圖。未取得實際政府影像驗證，範圍、地名、等高線、CORS 和手機效能均須實機核對。郊遊圖整區來源尚未提供。
- **預載目前畫面**：在有網絡時，分別儲存地形圖的底圖、中文地名及 20 米等高線，或郊遊圖的 OpenTopoMap 圖磚。離線可重新開啟 App、查看已存畫面及本機路線；圖心和已存畫面清單亦保存在本機。這是受限的單畫面預載，不等同整幅圖幅；與上方整幅試用互相獨立。

## 重要限制及安全

1. **這不是紙本 HM20C 的掃描版。** Topographic Map API 是官方一般地形底圖，不保證與印刷版 HM20C 的符號、配色、內容或圖幅完全一致。iB20000 等高線使用 Esri China (HK) 的公開副本，該副本最後修改於 **2021 年**，原始資料可能更舊或過時。若要真正保留紙本 HM20C 的全部特色，需取得有適當使用權的原始地理參考地圖／圖磚並接入；目前不能聲稱已做到。
2. **OpenTopoMap 不是地政總署的紙本郊區地圖。** 如果需要原版郊區地圖，亦需取得有適當使用權及地理參考的原始資料。兩種模式都沒有把其他地圖當成官方紙本地圖。
3. **離線不保證全港、全幅內容或永久保留。** 目前畫面預載只存單一畫面；試用整幅 TIFF 尚未以真實政府檔案或手機確認，跨幅須手動切換。必須在出發前以飛航模式重開並逐段檢查地名及等高線。瀏覽器可能清除儲存，清單只代表當時儲存成功，不代表地圖內容現在仍正確或完整；缺失時不可依賴畫面導航。
4. 路線是人手繪製的直線或匯入資料，不代表可通行的山徑，距離亦不包含高低起伏。地圖、地名和路線均可能有誤或過時。出發前請核對最新官方資訊，帶備紙本地圖及指南針，勿單靠手機。
5. **旋轉角度只是使用者提供的估算，未經逐張紙圖驗證。** 真北、方格北和磁北不同：HM20C 同時標示香港 1980 及 WGS84 UTM 方格網；僅以 UTM 分區不能證明紙圖邊緣或某一版紙圖的朝向。自動模式只按畫面中心與近似數碼圖幅套用固定值，跨幅可能跳變，圖幅與紙圖邊緣亦可能不同；它不是磁偏角校正，不能用作精確量度方位。請對照所用紙圖的偏角圖及指南針。比例校準後，地形圖中央約 **5 cm 對應 1 km**；實際比例仍受投影及螢幕設定影響。

## 離線預載及實測

### 安裝與準備

以穩定 HTTPS 網址的正式建置版在手機瀏覽器開啟（開發伺服器不提供離線功能；臨時預覽網址可能失效）。iPhone／iPad 在 Safari 按「分享」→「加入主畫面」；Android 在 Chrome 選單選「安裝應用程式」或「加到主畫面」。安裝後由主畫面圖示重新開啟，並在出發時會用的**同一個瀏覽器／主畫面 App**及同一網址下載；不同瀏覽器或主畫面 App 的儲存可能分開。

### 整幅 iB20000 地形圖試用

1. 按地圖右側下載圖示，選「整幅地形圖」及數碼圖幅 T1–T18。預選值按圖心估算，請以[官方數碼圖幅索引](https://www.landsd.gov.hk/doc/en/mapping/digital-map/common/index/ib20_index.pdf)核對。數碼 T1 是一幅地圖，紙本 HM20C 的 1 號是標題及圖例；數碼與紙圖邊界未逐一核實。
2. 按「嘗試直接下載」。手機直接向地政總署下載，不經 Vercel；官方伺服器是否容許瀏覽器跨網站讀取（CORS）、實際下載格式及網址流程尚未驗證。
3. 若直連失敗，按「官方下載」或「官方產品頁」在手機下載同一圖幅，返回同一個 App，按「選取手機 TIFF／ZIP」。檔案只在手機本機處理，不上傳到 Arena、Vercel 或本 App。ZIP 必須恰有一個 TIFF；若有多個，先在手機解壓並選擇正確 TIFF。輸入檔及解壓後 TIFF 各以 200 MB 為上限；[地政總署資料量表](https://www.landsd.gov.hk/doc/tc/mapping/digital-map/datasize.pdf)列 iB20000 TIFF 平均約 12 MB，但實際檔案、解壓記憶體與裝置配額可能不同。
4. 等待「已儲存在此裝置」，按「立即查看」或圖幅清單的「查看」。只會顯示該圖幅，不疊加地形 API、中文地名或 Esri 等高線；**TIFF 本身是否包含及清晰呈現地名與等高線仍須核對**。圖幅邊界外留白；可存多張但一次只顯示一張，跨幅須手動切換；若圖心離開目前圖幅會警告，不可在範圍外加路點。郊遊圖與其獨立，切換後不會混合。
5. 使用飛航模式**重新開啟**主畫面 App，逐段平移並對照紙圖及最新官方資訊，確認路線、地名、等高線、方向及圖幅邊界。瀏覽器可能因儲存空間、私隱模式或系統政策清除檔案；任何缺漏都不應依賴作導航，仍須帶紙圖和指南針。

這是**實驗性**功能：目前只用合成 GeoTIFF／ZIP 測試，尚未取得任何實際政府 TIFF；不保證其投影標籤、壓縮格式、內容、覆蓋、直連或手機性能適用。匯入會檢查 TIFF 區塊索引、地理參考、圖幅索引範圍抽樣和少量像素；不是逐像素完整性、等高線、地名或來源真偽驗證。範圍抽樣不足會顯示「並非整幅」，與所選圖幅不符會拒絕。支援有標明 EPSG:2326、4326 或 3857、像素面積型地理參考的 TIFF；其他格式、單個解碼區塊過大或解壓／空間不足時會報錯，不會以失敗下載覆蓋先前已存圖幅。

程式使用 EPSG:1825 的香港 1980 至 WGS84 轉換，按 proj4js 的 position-vector 慣例反轉官方 coordinate-frame 旋轉參數，並以 CSDI 數碼索引控制點回歸測試；分塊像素重投影及旋轉仍須以真實地圖與紙圖檢查。圖幅只是數碼地形參考，不能聲稱是已驗證的紙本 HM20C 掃描。

### 原有「目前畫面」預載

選地形圖或郊遊圖並移到需要的位置，在離線視窗選「目前畫面」及「下載目前畫面」。每次只存當下比例的一個畫面和少量邊緣，需移動後重複；不同底圖及校準可能要另外下載。每次最多 80 張圖磚，逐張間隔 350 毫秒。地形圖包括 API 底圖、中文地名及 20 米等高線；郊遊圖只存獨立 OpenTopoMap。若正使用本機圖幅，須先切回原有地形圖才能預載其即時畫面。飛航模式重開後亦須逐段檢查。

正式版 Service Worker 快取程式、圖磚和等高線查詢；等高線必須可用 CORS 完整讀取所有分頁，失敗／中止不記作完成。部分圖磚服務以不透明回應儲存時可能每張計作約 7 MB 或更多；下載過的圖磚會重用，清除「已存畫面」不會刪除本機整幅圖、路線或書籤。地圖供應商的可用性與離線預載授權須於實際部署時核實，避免大量請求公共服務。

## 來源、條款及部署原則

- [地政總署 iB20000 開放資料](https://data.gov.hk/tc-data/dataset/hk-landsd-openmap-development-hkms-digital-b20k)有 18 幅數碼地形圖；使用者提供的 HTML／XML 元數據和目錄只描述資料，並非實際圖像。一般 [CSDI 公開資料條款](https://portal.csdi.gov.hk/csdi-webpage/doc/TNC)容許免費下載、複製及分發，須遵守來源註明及相關條款；特定產品元數據／授權亦須逐一核對。互動地圖 API 的圖磚預載權利不能由此推定。用戶選取的任意檔案來源須自行核實。
- Vercel 只部署 App 程式、介面及小型索引，**不打包、上傳或保存**整幅地圖、GeoTIFF、圖磚資料庫或離線圖包。試用功能的官方直連從手機到地政總署；瀏覽器 CORS 不會因重新導向而繞過。後備的手機本機選檔亦不經伺服器；離線影像必須儲存在使用者自己的裝置。
- [MyMapHK 官方 App](https://apps.apple.com/hk/app/mymaphk/id793615275)有自己的 iB20000 離線功能，與本 App 的儲存不互通。[地政總署數碼地圖介紹](https://www.landsd.gov.hk/tc/survey-mapping/mapping/multi-scale-topographic-mapping/digital-map.html)稱數碼及相應紙圖同方式索引，但邊界和內容未逐一核實。
- 五張郊區圖的整區來源及授權仍未確定；不會把 OpenTopoMap 或政府互動服務的大量圖磚當作已授權整幅圖包，也不會將替代圖稱為官方紙本郊區圖。

## 等高線資料調查

- 地政總署 [iB1000](https://www.hkmapmeta.gov.hk/mcs/home/web/data/lands/iB1000.html) 在適用地區含 2 米等高線。等高距較密不等於垂直／水平位置一定更準確，也未必適合在 1:20,000 畫面全部顯示。
- [官方 CSDI iB1000 FeatureServer](https://portal.csdi.gov.hk/server/rest/services/common/landsd_rcd_1637223748322_25497/FeatureServer?f=pjson) 經查只有 `TileIndex`：可查圖幅及下載連結，**不是直接提供等高線的查詢圖層**。官方原檔可下載，但需自行處理地理座標、更新、授權和服務部署。另一個列有 iB1000 WFS/WMS 的 [LandsD 政府部門 API 入口](https://api.portal.hkmapservice.gov.hk/about) 面向政府部門，頁面要求有意部門申請試用金鑰；不能當作已驗證可供公眾無金鑰使用的等高線 API。
- [Esri China (HK) iB1000 公開等高線服務](https://www.arcgis.com/home/item.html?id=86815de825f74309aa580033dbbff44e) 確實可查到 `CONTOURHEIGHT`，圖層最後更新 2022 年（個別原始資料可能更舊），不是地政總署即時 API，亦沒有精度或更新保證。此 App 為維持現有 HM20C 參考的 **20 米高距及 iB20000 圖層**，沒有悄悄換成 2 米資料或混用兩套等高線。若取得合適的新 API，須先核對覆蓋、日期、線型、授權及在手機上實測。

## 本機開發

```sh
npm install
npm run dev
```

瀏覽終端顯示的網址。`npm run build` 產生的 `dist/` 可靜態部署；用 `npm run preview` 在本機測試正式建置的離線程式。除了 localhost，離線功能需要 HTTPS。地圖和等高線由使用者瀏覽器直接向各供應商讀取。

```sh
npm test                         # GPX、距離、投影、GeoTIFF／ZIP、儲存單元測試
npx playwright install chromium # 首次執行瀏覽器測試
npm run test:e2e                # 使用模擬圖磚測試手機流程，不依賴外部地圖
npm run test:e2e:offline        # 正式版、合成圖像／供應商：圖幅、ZIP、離線重開及失敗處理
```

## 來源與使用條款

- 底圖及中文地名：香港特別行政區政府地政總署 [Topographic Map API](https://portal.csdi.gov.hk/csdi-webpage/apidoc/TopographicMapAPI) 及 [Map Label API](https://portal.csdi.gov.hk/csdi-webpage/apidoc/MapLabelAPI)。使用受 [LandsD Map API 條款](https://portal.csdi.gov.hk/csdi-webpage/doc/TNC)約束，畫面保留地政總署標誌及「Map from Lands Department」。使用新域名 `mapapi.hkmapservice.gov.hk`（舊域名計劃於 2027-03-15 停用）。互動瀏覽共用最多 6 個同時圖磚請求；使用者發起離線預載時，另以單畫面、上限 80 張及逐張間隔下載。
- 等高線：地政總署 iB20000 ELEVLINE，經 [Esri China (HK) 公開圖層](https://www.arcgis.com/home/item.html?id=566289c35c214178b572a7e934a1cd9a)；`src/map/contours.js` 改自使用者的 [HKMAP](https://github.com/playerkousas-rgb/HKMAP/blob/main/js/contours.js)。資料僅供參考，以原始地政總署資料為準。
- 郊遊參考：地圖資料 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)、SRTM；地圖樣式 © [OpenTopoMap](https://opentopomap.org/)（CC BY-SA）。OpenTopoMap 要求避免大量下載；其公共服務的廣域離線預載許可未經確認，此程式不提供廣域批量下載。實際部署者須核對供應商現行條款。
- 圖幅自動選擇：地政總署 [iB20000 數碼圖幅索引](https://portal.csdi.gov.hk/server/rest/services/common/landsd_rcd_1637224132564_22637/FeatureServer/0?f=pjson) 的 WGS84 近似範圍；每幅角度是使用者的估算，不是從官方圖幅資料取得的角度。
