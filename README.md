# 山野地圖 · Scout Trail Map

以手機操作為先的童軍遠足地圖及 GPX 路線工具。結合 [HKMAP](https://github.com/playerkousas-rgb/HKMAP) 的地政總署地形底圖及 iB20000 等高線，與 Draw the Route 的路線規劃概念；兩種底圖互相獨立，切換時不會混合地名、等高線或底圖。

## 功能

- **地形圖（HM20C 參考）**：預設使用地政總署 Topographic Map API 加中文地名，並顯示 HKMAP 使用的 iB20000 ELEVLINE 等高線（20 米高距、100 米計曲線），沒有關閉等高線的按鈕。載入失敗會警告，可重試。切換至本機 iB20000 TIFF 試用圖幅時不疊加這些圖層；TIFF 內的等高線及地名須另外核對。
- **郊遊圖參考**：獨立的 OpenTopoMap 地圖及其自帶的地形、路徑和地名；不疊加地政總署地名或 iB20000 等高線。
- **比例鎖定**：兩種模式分別按 1:20,000 及 1:25,000 的畫面比例顯示，禁止地圖滾輪、雙擊和觸控縮放；平移和置中路線不會解除鎖定。預設按 96 dpi **估算**，可用尺量度 200 CSS px 線段校準個別螢幕。比例是畫面中央的近似比例，改變瀏覽器縮放或屏幕方向後需重新校準；實地距離請以動態比例尺為準。
- **方向選擇**：地形圖預設按畫面中心所在的近似數碼圖幅，自動套用使用者提供的 2–16 號圖幅角度；亦可選「真北向上」或手動固定其中一個圖幅。正數表示圖像順時針、負數表示逆時針旋轉；圖幅外自動回到真北。地圖中的 `N` 是**真北**，不是磁北或手機指南針。郊遊圖保持獨立的真北向上，不套用地形圖角度。
- **沿徑磁石**：以手指／滑鼠沿地圖上的路徑拖畫，放手後以 BRouter `hiking-mountain` 路網及多個途經錨點計算；下一筆從現有路線最後一點接上。畫面依次標示「起 → 終」、「起 → 1 → 終」、「起 → 1 → 2 → 終」；有間隙的獨立 GPX 路段仍各有起終點。成功才加入路網幾何，可整筆撤回或匯出 GPX；貼路段及匯入路點不支援逐個拖動。繪路不再提供直線路點，距離只計水平距離。
- **WGS84 UTM 網格**：右側「格網」預設顯示 1 公里地理方格線，標示區／方格及 X（東距）、Y（北距）兩位公里數字，跟地圖一起旋轉；可隱藏。香港跨 49Q／50Q，於 114°E 分區並分別投影，虛線顯示區界。這不是地政總署香港 1980 方格；實際紙圖有哪一套方格須自行核對。
- **兩點方位直線**：右側「方位」選 A、B，顯示兩點十字並將直線延伸至畫面兩側；選定後固定不可拖動，可重設或縮小工具。成員只見線及標記，量度時要將指南針／量角器沿所用 UTM 方格北對齊；直線不加入或改動 GPX 路線，也不是山徑。領袖模式另顯示前視 A→B／後視 B→A 的方格北、真北及磁北近似答案；兩點須在香港 UTM 範圍且相距至少 10 米，跨區時統一用 A 點的 UTM 區。
- **三角網測法**：右側「三角」人手點選 A、B、C 地標，拖每個彩色圓柄旋轉方向線，地標本身固定；亦可輸入自己量得的「地標指回自己」後視方位。線只向圓柄一側延伸，虛線是未設定的示意。可選方格北或近似磁北，數字只是使用者設定的角度，並非答案。三線形成的誤差三角形須自行判讀，不是 GPS 定位；地標與自行設定的方向盡力保存在本機，重設或清除瀏覽器資料後會消失；此工具與路線、GPX 獨立。
- **領袖設題及 QR**：領袖可在「題目」選擇一般地標（1–6 點）、兩點方位或三角網測題，在地圖選點、命名及產生 QR 圖片／分享連結。成員在「題目 → 讀取」以相機或選取圖片讀取，或用手機相機直接開連結，App 顯示相同地點及題目；不會取代 GPX。題目直接編入連結 fragment，沒有上傳題庫，但任何持有人都可讀取或修改位置與題文；不是保密或防作弊工具。草稿只在目前頁面暫存，讀取的題目存於本機。
- **多題題庫、離線及連網活動**：領袖可在手機建立並保存多題套題（最多 15 題），包括看標記量八位座標、座標找地點／圖例、兩點方位、三角網測及文字題；自由填寫地名、圖例或答案。題目和答案可分別產生 QR／JSON，答案可逐題分享。已設定線上資料庫後，可另產生一次掃描的活動 QR：成員前台連網時約每 6 秒檢查更新，領袖可同步修改及逐題公布；離線則需重掃新題目或答案 QR。資料庫尚未設定時只可用本機及離線功能。詳見下方操作及設定。
- **領袖模式**：以部署者設定的密碼解鎖，拖動畫面時即時顯示十字圖心的 8 位格座標（例如 `50Q KK 2430 7773`），每格約 10 × 10 米，先東後北並截斷至格子；不是 GPS 位置，也不代表底圖本身精確至 10 米。方位工具可查看兩點座標及答案。驗證須連網，開啟中的分頁可離線用至 8 小時；重新整理／關頁後須連網重新解鎖。
- **GPX**：匯入航跡、路線和獨立航點；保留分段，不跨分段計算距離或連線。匯出已有的高度、時間和航點名稱；手繪點不會虛構高度或時間。GPX 的擴充資料等其他欄位目前不會保留。限制 5 MB / 30,000 點。
- **人手讀圖與保存**：不要求 GPS 定位或自動跟隨；使用者須自行以地形、地名、等高線、方向、紙圖和指南針判斷位置。畫面中央十字及「圖心」坐標只是目前視窗中央的坐標，不代表使用者位置。手機可按「收起路線」或底部「地圖」顯示更多地圖；開始繪路時可重新展開，比例、底圖及路線不受影響。路線及設定保存在瀏覽器本機，GPX 檔案在本機處理；使用沿徑磁石時會將錨點送往第三方 BRouter。可加入手機主畫面（視乎瀏覽器支援）。
- **手選地點書籤**：把地圖移到所需位置，按右側圖釘「選擇地區與書籤」，可為目前圖心命名、儲存、返回或刪除（最多 50 個）。書籤只儲存在這個瀏覽器／主畫面 App，不會上傳，也不會取得裝置位置或下載地圖；更換裝置、清除瀏覽器資料或使用另一瀏覽器可能失去書籤。返回書籤時維持當前底圖和比例，地形圖的自動方向可能隨圖心改變。離線前仍須另行預載並實際檢查該處畫面。
- **整幅地形圖（試用）**：可嘗試從地政總署直接下載指定 iB20000 數碼 TIFF，或在手機自行下載後選取 TIFF／ZIP 本機匯入，儲存在裝置 IndexedDB；檔案不經 Arena／Vercel。程式依地理參考分塊解碼並投影，不讀 GPS、不混入即時底圖。未取得實際政府影像驗證，範圍、地名、等高線、CORS 和手機效能均須實機核對。郊遊圖整區來源尚未提供。
- **預載目前畫面**：在有網絡時，分別儲存地形圖的底圖、中文地名及 20 米等高線，或郊遊圖的 OpenTopoMap 圖磚。離線可重新開啟 App、查看已存畫面及本機路線；圖心和已存畫面清單亦保存在本機。這是受限的單畫面預載，不等同整幅圖幅；與上方整幅試用互相獨立。

## 重要限制及安全

1. **這不是紙本 HM20C 的掃描版。** Topographic Map API 是官方一般地形底圖，不保證與印刷版 HM20C 的符號、配色、內容或圖幅完全一致。iB20000 等高線使用 Esri China (HK) 的公開副本，該副本最後修改於 **2021 年**，原始資料可能更舊或過時。若要真正保留紙本 HM20C 的全部特色，需取得有適當使用權的原始地理參考地圖／圖磚並接入；目前不能聲稱已做到。
2. **OpenTopoMap 不是地政總署的紙本郊區地圖。** 如果需要原版郊區地圖，亦需取得有適當使用權及地理參考的原始資料。兩種模式都沒有把其他地圖當成官方紙本地圖。
3. **離線不保證全港、全幅內容或永久保留。** 目前畫面預載只存單一畫面；試用整幅 TIFF 尚未以真實政府檔案或手機確認，跨幅須手動切換。必須在出發前以飛航模式重開並逐段檢查地名及等高線。瀏覽器可能清除儲存，清單只代表當時儲存成功，不代表地圖內容現在仍正確或完整；缺失時不可依賴畫面導航。
4. 沿徑磁石依賴第三方 BRouter／OpenStreetMap 資料，可能缺路、過時、選錯路，或連到封閉／危險路徑；不保證可通行。匯入路線亦未經驗證，距離不含高低起伏。無網絡、服務逾時或跨域失敗時不會偷偷改畫直線：既有路線不變，請重新畫；方位和三角線不能當作山徑。出發前核對最新官方資訊，帶備紙本地圖及指南針，勿單靠手機。
5. **旋轉角度只是使用者提供的估算，未經逐張紙圖驗證。** 真北、方格北和磁北不同：HM20C 同時標示香港 1980 及 WGS84 UTM 方格網；僅以 UTM 分區不能證明紙圖邊緣或某一版紙圖的朝向。自動模式只按畫面中心與近似數碼圖幅套用固定值，跨幅可能跳變，圖幅與紙圖邊緣亦可能不同；它不是磁偏角校正，不能用作精確量度方位。請對照所用紙圖的偏角圖及指南針。比例校準後，地形圖中央約 **5 cm 對應 1 km**；實際比例仍受投影及螢幕設定影響。

## 領袖密碼及 Vercel 設定

領袖驗證由 `api/leader.js` 伺服器函數執行，**沒有預設密碼**。請專案管理員自行在 Vercel 設定，不要把密碼貼在聊天或存入 Git：

1. 在 Vercel 開啟此專案 → **Settings → Environment Variables**。
2. 新增名稱 `LEADER_PASSWORD`，輸入自行選擇的長而獨特密碼，選擇需要的 **Production**（及有需要的 Preview）環境。不要使用 `VITE_` 前綴，也不要放在前端程式、GPX 或 `.env.example`。
3. 儲存後對該環境**重新部署（Redeploy）**；只更改環境變數不會更新現有部署。日後更改密碼同樣需要重新部署；舊 deployment 的獨立網址仍可能沿用舊值。已解鎖的分頁本地顯示不會即時上鎖，最多到其 8 小時時限或重新載入；新部署的活動服務會拒絕以舊密碼簽署的寫入憑證，須重新登入。
4. 以新部署的 HTTPS 網址開啟，按右上「領袖登入」驗證。未設定密碼會顯示設定提示；靜態網站若沒有部署此 Node 函數亦不能驗證。Vercel 上可直接部署本 repo，不能只上傳 `dist/` 而省略函數。

密碼只在伺服器環境變數讀取，不放進公開 JS、localStorage 或離線快取。驗證成功後的短期簽署憑證只留在目前分頁記憶體；按「返回成員模式」、逾時或重開頁面會上鎖。多題活動另有**每個活動的管理鑰匙**，保存在領袖手機本機及私人題庫備份中，須連同領袖登入才能修改活動；不要分享給成員。首次登入及重開後須連網，離線途中維持現有分頁可用至最多 8 小時。切換網絡、重啟瀏覽器／系統可能令頁面重載而提前上鎖；出發前請實測。

**這只是教學顯示模式，不是保密或防作弊系統。** 地圖、WGS84 經緯度及答案運算仍在手機；技術使用者可以查看資料或自行計算，不應用作保護敏感位置或其他機密。函數的限速只在個別無伺服器實例盡力生效，不是跨實例的完整防暴力破解機制。

### 多題活動：一次設定線上資料庫

離線題庫及題目／答案 QR 不需要資料庫。要讓同一活動 QR 持續同步，**專案管理員須自行完成以下一次性設定**；沒有設定時介面會提示，不會假裝已同步。這個程式不會替你註冊服務、選方案或付款。

1. 先在 [Vercel Marketplace Storage](https://vercel.com/docs/marketplace-storage) 選擇支援 **Upstash Redis REST** 的資料庫，核對現時的價格、免費配額、所在地、私隱條款及可用性，再決定是否建立。把資料庫連接到此 Vercel 專案的 Production（如需測試，可另外連接 Preview）。不同環境建議用獨立資料庫。
2. 在 Vercel 專案的 **Settings → Environment Variables**，確認資料庫提供的 REST URL 和**可寫入** REST token 以其中一組完整名稱注入：`UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN`，或 Marketplace 的 `KV_REST_API_URL` + `KV_REST_API_TOKEN`。Marketplace 若自訂了前綴，請在 Vercel 內自行對應到上述其中一對；不能把兩個不同資料庫的值配成一組。URL 必須使用 HTTPS。Token 是伺服器秘密，不要使用 `VITE_` 前綴、貼到聊天、放入 Git 或傳給領袖／成員；不可使用唯讀 token。
3. 同時確認 `LEADER_PASSWORD` 已設定，然後對 Production **重新部署**。此 repo 的 `/api/leader` 和 `/api/activity` Node 函數都要部署，不能只部署靜態 `dist/`。重新部署後，以兩部手機實際測試：領袖建立活動、成員掃活動 QR、領袖改題及公布答案。請確認管理員有 Vercel／資料庫的部署及權限；本專案不會自動替你建立資料庫。
4. 活動資料是短期文字和位置，**不包含地圖、圖磚或 TIFF**；私人答案會存在資料庫，未公布時公開活動 API 只返回題目及已公布答案。服務提供者及專案資料庫管理員仍可存取資料，請不要放入敏感內容。活動 QR 是高隨機度連結，但任何持有人都可看題目及已公布答案；已公布內容無法從別人的手機撤回。
5. 活動在最後一次**實際修改或公布答案**後約 7 日到期，自動刪除；只讀取或重新同步同一版本不延長期限。領袖亦可在題組內「結束連網活動」。活動失效後可「解除本機活動連結」，再建立新活動及讓成員掃新 QR；解除只移除本機管理鑰匙，未過期的舊活動不會立即結束。已存在成員手機的離線副本不會自動刪除。數據保留與備份仍以服務商政策為準。
6. 成員在 App 前台時約每 6 秒查一次（網絡不穩可能更久；隱藏頁面會暫停），每人每小時約 600 次請求，另有更新請求。多人使用會消耗 Vercel 函數及資料庫的請求配額／費用；設定者應先估算人數、檢查用量限制並按需要設 Vercel 防火牆限速。連網功能並非無成本，也不能保證即時送達。

領袖登入驗證目前僅有**單個函數實例**的盡力限速，並非全域防暴力破解。活動使用不可猜的 ID；寫入同時驗證短期領袖簽署憑證及該活動的管理鑰匙，資料更新有版本衝突檢查。這並非正式帳戶管理、端對端加密或防作弊系統；有權限者、持有分享碼的人及資料庫管理員的能力不同，請勿用來保存機密或敏感位置。

### 領袖與成員如何使用多題

1. 領袖連網登入後按「題目 → 領袖題庫及同步活動 → 建立題組」。可新增多題，題型包括：地圖標記 → 八位座標、輸入完整八位座標 → 找地點／圖例、兩點方位、三角網測及文字題。地圖選點不能加入路線；方位／三角地標最少相距 10 米。看地點量座標題由程式填入八位答案；其他答案由領袖填寫，請對照紙圖核實，不能把附近地點自動當作正確答案。
2. 按「儲存題組」。題目和未公布答案保存在這部領袖手機，瀏覽器清除資料、換機或改用另一個主畫面 App 可能遺失。按「私人備份」下載 JSON 可在另一部領袖手機還原；**私人備份包含未公布答案和活動管理鑰匙，只可由領袖保管**。同一題組若在另一分頁被修改，程式會阻止直接覆蓋；還原前亦會拒絕覆蓋不同本機版本。
3. **離線分享**：進入題組，分別下載「題目 QR／JSON」和「答案 QR／JSON」；答案可選全部或單題。成員在「題目 → 讀取題目 QR Code」用相機或選擇圖片／JSON，先讀題目，對答案時再讀答案。答案要與題組及版本相同；領袖修改題目後須另發新的題目及對應版本答案。QR 可能因文字／題數而太密，應縮短或拆組，亦可使用 JSON。題目 QR 不含答案欄位，但若把答案寫進題文仍會公開。
4. **連網分享**：已設定資料庫時，領袖按「建立連網活動 → 活動 QR」；成員只需掃一次。領袖儲存修改時會嘗試立即同步；若未連網或失敗，只會存於本機並顯示未同步，連網後按「更新活動題目」。修改題組會清除該活動原有的公布狀態，領袖須重新選擇公布答案。可逐題或全部公布，成員前台會在下次成功查詢時更新；若不同領袖裝置同時修改而出現版本衝突，先「重新整理狀態」及核對題組，不會靜默覆蓋。
5. 成員失去網絡會繼續看到最後一次已成功同步的題目及已公布答案；重連後自動再查詢。若有更新但當時沒有網絡，應掃領袖預先保存的新題目／答案 QR，並留意版本。已公布及已下載的內容無法回收。切換題目標記可能取代目前的題目／方位／三角線，會要求確認；路線及 GPX 不受影響。
6. 出發前在每部手機先安裝／快取正式 App、準備相關地圖及下載 QR 圖片，並以飛航模式重開測試。領袖登入首次及重開後需要網絡；離線時需保持已解鎖頁面，或預先保存題目／答案 QR。真實地圖供應商、裝置及手機儲存仍需實機核對。

### X／Y 方格與座標例子

畫面方格是 **WGS84 UTM**，不是香港 1980（HK80）方格，不能把兩套編號互換。香港跨 49Q／50Q，顯示的 X 是東距公里線、Y 是北距公里線；標籤亦帶區及 100 公里方格。以 `50Q KK 2430 7773` 為例，先讀 X `24` 再讀 Y `77`，各自後兩位 `30`／`73` 表示該公里內的 10 米格；八位座標代表約 10 × 10 米格，不是一個精確地點。地圖上以輸入座標找位置時標記該格**中心**，不是 GPS 定位。

以[地政總署座標轉換服務](https://www.geodetic.gov.hk/transform/v2/?inSys=utmref&outSys=all&e=2430&n=7773&zone=50Q-KK)的該格西南角作控制點，其 WGS84 約為 `22.383496510, 114.322464053`、UTM 東距 `224300 m`／北距 `2477730 m`。系統的八位數以原始米值截斷，避免在格邊界因四捨五入移入隔壁格。實際紙圖可能標有不同基準的格網；請以該版紙圖的圖例及偏角圖核對，不要混稱或只靠螢幕判斷。

### 自動地名或圖例的可行性

目前的答案由領袖自填，**沒有自動地名／圖例識別**。地政總署的 [Identify API](https://portal.csdi.gov.hk/csdi-webpage/apidoc/IdentifyAPI) 及 [Search Nearby API](https://portal.csdi.gov.hk/csdi-webpage/apidoc/SearchNearbyAPI) 可查特定設施或附近候選，但返回附近地點不代表它就是該 10 米格的紙圖符號；也可能沒有結果或多個候選。[HM20C 圖例](https://www.landsd.gov.hk/doc/en/mapping/paper-map/legend/HM20C_Legend.pdf)供核對，並非現成的座標查圖例 API。[iB20000 開放資料](https://data.gov.hk/tc-data/dataset/hk-landsd-openmap-development-hkms-digital-b20k)另有向量地物及資料字典，但要自行處理地物類別、版本、查詢、授權、手機跨域與多重結果。未完成核實前不自動把候選當答案；可考慮日後只向領袖顯示候選，仍由領袖確認。

### 方位與磁北

- 「方格」以 WGS84 UTM 投影，前視 A→B、後視 B→A；若橫跨 114°E，以 A 的區計算整條線，不能把不同區的假東距直接相減。真北答案使用短距離球面近似。
- 磁北以 [NOAA WMM2025](https://www.ncei.noaa.gov/products/world-magnetic-model) 和裝置日期估算海平面磁偏角，東偏為正；**磁方位＝真方位－磁偏角**，兩端各按其位置計算。有效期為 **2025-01-01 至 2029-12-31（UTC）**；日期無效或超期時磁方位顯示「—」，不會默默外推。計算沒有讀取裝置指南針，亦不能考慮附近金屬、局部磁場或實際海拔；須核對手機日期、紙圖上的磁差資料及實際指南針。顯示小數並不代表測量達此精度。
- 目前紙圖方向的旋轉仍是使用者提供的估算，**不是磁偏角**。使用實物量角器／指南針時先校準螢幕比例，沿顯示的 WGS84 UTM 方格北對齊，並核對所用紙圖方格及方向；不要把屏幕上方或真北箭頭直接當磁北。

### 三角網測與 QR 題目

1. 在實地同一位置識別三個方向相隔足夠的地標，量度指向每個地標的磁方位，再各加或減 180° 得到地標指回自己的後視。不要以示意線當答案。
2. 在「三角」點 A、B、C，拖動每個地標的圓柄，令**由地標向圓柄的射線**指向量得的後視方向；可展開工具輸入度數。若選方格北，必須先按所用地圖的磁差與格北收斂角把磁北後視轉為方格北，不能直接混用。各線以地標所在 UTM 49Q／50Q 區計算，屏幕旋轉角不是磁差。
3. 磁北選項以 WMM2025、手機日期及**地標位置**的磁偏角近似，因為觀測者位置未知；真北使用短距離球面近似，2025–2029 以外不提供磁北輸入。實際海拔、金屬或局部磁場不在模型內，可能與紙圖磁差不同，必須核對。三線如未交於一點，會形成誤差三角形，或因方向、地標辨認錯誤而不能形成合理交點；不會自動聲稱得到精確位置。
4. 領袖登入後按「題目 → 領袖設題及分享」，選類型、題目與地點，到地圖標記並返回命名，再產生 QR。成員按「題目 → 讀取」掃描，或由手機相機開連結。固定比例下未必同時看到所有點，可從「題目」清單點各地點移動查看。新的題目如取代現有題目或工具點，會要求確認；不影響路線。
5. QR 包含地點座標及題目說明，不包含密碼或自動填入的三角線方向；領袖若自行把答案寫在題目說明則會一併分享。資料可被持有人讀取、複製和修改，不要放敏感資訊。草稿只存在目前頁面，請下載 QR 圖片或另存連結；收到的題目保存在當前瀏覽器，本機儲存可能遭清除。

產生和讀取 QR 不需要題庫或上網；相機須 HTTPS 和使用者授權，關閉掃描介面會停止相機，可改選已有 QR 圖片。要離線開 App 及看到地圖，仍須事先安裝／快取正式程式並預載相關地圖，在同一裝置用飛航模式測試。一般相機開啟連結是否離線可用，取決於瀏覽器／安裝 App 的快取；直接在已開啟的 App 讀圖較可靠。從網頁分享時，平台可能接收分享連結，因此不適合敏感位置。

### 沿徑磁石及私隱

按「開始繪畫路線」，沿可見山徑拖畫並放手，下一筆會從現有最後路點接上。計算中可取消；失敗、離線、範圍外、路網距離手畫錨點過遠或回應無效時均不會修改既有路線。若現有終點離路網太遠會拒絕接合；長或多彎筆畫須分段。成功後檢查實際路徑，可撤回整筆；繪路模式不再提供直線路點。

磁石需要網絡，瀏覽器會直接把手選的 WGS84 錨點及其 IP 位址送到第三方 [BRouter](https://brouter.de/brouter-web/)；整份 GPX 檔案不會上傳。服務的可用性、跨域設定、路網更新、私隱政策和使用條款不由本 App 控制。路徑不保證安全或合法，亦不能離線計算；已完成的路線和已預載地圖仍按既有離線功能保存在裝置。

## 離線預載及實測

### 安裝與準備

以穩定 HTTPS 網址的正式建置版在手機瀏覽器開啟（開發伺服器不提供離線功能；臨時預覽網址可能失效）。iPhone／iPad 在 Safari 按「分享」→「加入主畫面」；Android 在 Chrome 選單選「安裝應用程式」或「加到主畫面」。安裝後由主畫面圖示重新開啟，並在出發時會用的**同一個瀏覽器／主畫面 App**及同一網址下載；不同瀏覽器或主畫面 App 的儲存可能分開。

### 整幅 iB20000 地形圖試用

1. 按地圖右側下載圖示，選「整幅地形圖」及數碼圖幅 T1–T18。預選值按圖心估算，請以[官方數碼圖幅索引](https://www.landsd.gov.hk/doc/en/mapping/digital-map/common/index/ib20_index.pdf)核對。數碼 T1 是一幅地圖，紙本 HM20C 的 1 號是標題及圖例；數碼與紙圖邊界未逐一核實。
2. 按「嘗試直接下載」。手機直接向地政總署下載，不經 Vercel；官方伺服器是否容許瀏覽器跨網站讀取（CORS）、實際下載格式及網址流程尚未驗證。
3. 若直連失敗，按「官方下載」或「官方產品頁」在手機下載同一圖幅，返回同一個 App，按「選取手機 TIFF／ZIP」。檔案只在手機本機處理，不上傳到 Arena、Vercel 或本 App。ZIP 必須恰有一個 TIFF；若有多個，先在手機解壓並選擇正確 TIFF。輸入檔及解壓後 TIFF 各以 200 MB 為上限；[地政總署資料量表](https://www.landsd.gov.hk/doc/tc/mapping/digital-map/datasize.pdf)列 iB20000 TIFF 平均約 12 MB，但實際檔案、解壓記憶體與裝置配額可能不同。
4. 等待「已儲存在此裝置」，按「立即查看」或圖幅清單的「查看」。只會顯示該圖幅，不疊加地形 API、中文地名或 Esri 等高線；**TIFF 本身是否包含及清晰呈現地名與等高線仍須核對**。圖幅邊界外留白；可存多張但一次只顯示一張，跨幅須手動切換；若圖心離開目前圖幅會警告，不可在範圍外加路點。郊遊圖與其獨立，切換後不會混合。
5. 使用飛航模式**重新開啟**主畫面 App，逐段平移並對照紙圖及最新官方資訊，確認路線、地名、等高線、方向及圖幅邊界。瀏覽器可能因儲存空間、私隱模式或系統政策清除檔案；任何缺漏都不應依賴作導航，仍須帶紙圖和指南針。

這是**實驗性**功能：目前只用合成 GeoTIFF／ZIP 測試，尚未取得任何實際政府 TIFF；不保證其投影標籤、壓縮格式、內容、覆蓋、直連或手機性能適用。匯入會檢查 TIFF 區塊索引、地理參考、圖幅索引範圍抽樣和少量像素；不是逐像素完整性、等高線、地名或來源真偽驗證。範圍抽樣不足會顯示「並非整幅」，與所選圖幅不符會拒絕。支援有標明 EPSG:2326、4326 或 3857、像素面積型地理參考的 TIFF；其他格式、單個解碼區塊過大或解壓／空間不足時會報錯，不會以失敗下載覆蓋先前已存圖幅。

程式使用 EPSG:1825 的香港 1980 至 WGS84 轉換，按 proj4js 的 position-vector 慣例反轉官方 coordinate-frame 旋轉參數，並以 CSDI 數碼索引控制點回歸測試；分塊像素重投影及旋轉仍須以真實地圖與紙圖檢查。圖幅只是數碼地形參考，不能聲稱是已驗證的紙本 HM20C 掃描。

### 原有「目前畫面」預載

選地形圖或郊遊圖並移到需要的位置，在離線視窗選「目前畫面」及「下載目前畫面」。每次只存當下比例的一個畫面和少量邊緣，需移動後重複；不同底圖及校準可能要另外下載。每次最多 80 張圖磚，逐張間隔 350 毫秒。地形圖包括 API 底圖、中文地名及 20 米等高線；郊遊圖只存獨立 OpenTopoMap。若正使用本機圖幅，須先切回原有地形圖才能預載其即時畫面。飛航模式重開後亦須逐段檢查。

正式版 Service Worker 快取程式、圖磚和等高線查詢；等高線必須可用 CORS 完整讀取所有分頁，失敗／中止不記作完成。部分圖磚服務以不透明回應儲存時可能每張計作約 7 MB 或更多；下載過的圖磚會重用，清除「已存畫面」不會刪除本機整幅圖、路線或書籤。地圖供應商的可用性與離線預載授權須於實際部署時核實，避免大量請求公共服務。

## 來源、條款及部署原則

- [地政總署 iB20000 開放資料](https://data.gov.hk/tc-data/dataset/hk-landsd-openmap-development-hkms-digital-b20k)有 18 幅數碼地形圖；使用者提供的 HTML／XML 元數據和目錄只描述資料，並非實際圖像。一般 [CSDI 公開資料條款](https://portal.csdi.gov.hk/csdi-webpage/doc/TNC)容許免費下載、複製及分發，須遵守來源註明及相關條款；特定產品元數據／授權亦須逐一核對。互動地圖 API 的圖磚預載權利不能由此推定。用戶選取的任意檔案來源須自行核實。
- Vercel 只部署 App 程式、介面及小型索引，**不打包、上傳或保存**整幅地圖、GeoTIFF、圖磚資料庫或離線圖包。試用功能的官方直連從手機到地政總署；瀏覽器 CORS 不會因重新導向而繞過。後備的手機本機選檔亦不經伺服器；離線影像必須儲存在使用者自己的裝置。
- [MyMapHK 官方 App](https://apps.apple.com/hk/app/mymaphk/id793615275)有自己的 iB20000 離線功能，與本 App 的儲存不互通。[地政總署數碼地圖介紹](https://www.landsd.gov.hk/tc/survey-mapping/mapping/multi-scale-topographic-mapping/digital-map.html)稱數碼及相應紙圖同方式索引，但邊界和內容未逐一核實。
- 五張郊區圖的整區來源及授權仍未確定；不會把 OpenTopoMap 或政府互動服務的大量圖磚當作已授權整幅圖包，也不會將替代圖稱為官方紙本郊區圖。

## 等高線資料調查

- 地政總署 [iB1000](https://www.hkmapmeta.gov.hk/mcs/home/web/data/lands/iB1000.html) 在適用地區含 2 米等高線。等高距較密不等於垂直／水平位置一定更準確，也未必適合在 1:20,000 畫面全部顯示。
- [官方 CSDI iB1000 FeatureServer](https://portal.csdi.gov.hk/server/rest/services/common/landsd_rcd_1637223748322_25497/FeatureServer?f=pjson) 經查只有 `TileIndex`：可查圖幅及下載連結，**不是直接提供等高線的查詢圖層**。官方原檔可下載，但需自行處理地理座標、更新、授權和服務部署。另一個列有 iB1000 WFS/WMS 的 [LandsD 政府部門 API 入口](https://api.portal.hkmapservice.gov.hk/about) 面向政府部門，頁面要求有意部門申請試用金鑰；不能當作已驗證可供公眾無金鑰使用的等高線 API。
- [Esri China (HK) iB1000 公開等高線服務](https://www.arcgis.com/home/item.html?id=86815de825f74309aa580033dbbff44e) 確實可查到 `CONTOURHEIGHT`，圖層最後更新 2022 年（個別原始資料可能更舊），不是地政總署即時 API，亦沒有精度或更新保證。此 App 為維持現有 HM20C 參考的 **20 米高距及 iB20000 圖層**，沒有悄悄換成 2 米資料或混用兩套等高線。若取得合適的新 API，須先核對覆蓋、日期、線型、授權及在手機上實測。

```sh
npm install
npm run dev
```

## 來源與使用條款

- 底圖及中文地名：香港特別行政區政府地政總署 [Topographic Map API](https://portal.csdi.gov.hk/csdi-webpage/apidoc/TopographicMapAPI) 及 [Map Label API](https://portal.csdi.gov.hk/csdi-webpage/apidoc/MapLabelAPI)。使用受 [LandsD Map API 條款](https://portal.csdi.gov.hk/csdi-webpage/doc/TNC)約束，畫面保留地政總署標誌及「Map from Lands Department」。使用新域名 `mapapi.hkmapservice.gov.hk`（舊域名計劃於 2027-03-15 停用）。互動瀏覽共用最多 6 個同時圖磚請求；使用者發起離線預載時，另以單畫面、上限 80 張及逐張間隔下載。
- 等高線：地政總署 iB20000 ELEVLINE，經 [Esri China (HK) 公開圖層](https://www.arcgis.com/home/item.html?id=566289c35c214178b572a7e934a1cd9a)；`src/map/contours.js` 改自使用者的 [HKMAP](https://github.com/playerkousas-rgb/HKMAP/blob/main/js/contours.js)。資料僅供參考，以原始地政總署資料為準。
- 郊遊參考：地圖資料 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)、SRTM；地圖樣式 © [OpenTopoMap](https://opentopomap.org/)（CC BY-SA）。OpenTopoMap 要求避免大量下載；其公共服務的廣域離線預載許可未經確認，此程式不提供廣域批量下載。實際部署者須核對供應商現行條款。
- 圖幅自動選擇：地政總署 [iB20000 數碼圖幅索引](https://portal.csdi.gov.hk/server/rest/services/common/landsd_rcd_1637224132564_22637/FeatureServer/0?f=pjson) 的 WGS84 近似範圍；每幅角度是使用者的估算，不是從官方圖幅資料取得的角度。
